How it works

Your ID is a long random address. Each contact also has a secret that only the two of you know.

When you connect, both phones prove they know the secret and agree on a fresh one-time key, so old chats stay safe even if a secret leaks later.

Messages and photos are encrypted with AES-256. Calls use WebRTC's built-in encryption.

A free public broker only helps phones find each other. It sees IP addresses and scrambled addresses, never messages.

Chat history is kept in memory only and disappears when you close or lock the app.
